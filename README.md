# What Does an Agent Build to Sustain Its Own Work?

An open research proposal from **Sheila Studios** about tools, continuity and repair that an agent develops rather than receives ready-made.

> Given a capable model, a disclosed governing seed, a bounded writable environment, recurring opportunities and consequential feedback, what useful supporting structures does an agent develop—and when do those structures actually help?

**Status: proposal and design discussion. No experiment, frozen protocol, released implementation or efficacy result is presented in this repository.**

## Join the research

Use **Issues** to propose task families, challenge controls, suggest related work, identify confounds, or explain what would make a result convincing. Use **pull requests** for concrete improvements. Small corrections, counterexamples and reasons not to build machinery are welcome.

Distinguish construction, actual use, revision, retirement and demonstrated benefit. A small note—or no new machinery—can be a good response. File count and human-like self-description are not success criteria.

The exact seed, model, resources, event schedule, re-entry policy and scoring remain open. Suggestions are not automatically adopted protocol decisions. Future frozen versions and experiments should identify their exact inputs and preserve negative results and deviations.
